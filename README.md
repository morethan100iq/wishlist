# Вишлист

Личный список желаний. Вставляешь ссылку на товар — название, картинка и цена подтягиваются сами.
Данные лежат в браузере (localStorage), сервер не нужен.

## Что умеет

- Добавление по ссылке: og-теги, JSON-LD, `itemprop=price`, плюс отдельный разбор Wildberries через открытый JSON
- Кнопка «Обновить цены» — перепроверяет весь список и показывает, где цена упала
- Ручное добавление, приоритеты, заметки, отметка «куплено»
- Ссылка «Поделиться» — весь список пакуется в сам URL, друг открывает без регистрации
- Экспорт и импорт JSON
- Вставка ссылки (Ctrl+V) в любом месте страницы сразу создаёт карточку

## Деплой

### GitHub Pages (просто, только `index.html`)

```bash
git init && git add . && git commit -m "wishlist"
git branch -M main
git remote add origin git@github.com:USER/wishlist.git
git push -u origin main
```

Settings → Pages → Source: `main` / root. Через минуту сайт на `USER.github.io/wishlist`.
Цены будут читаться через публичные CORS-прокси — работает, но не с каждым магазином.

### Vercel (рекомендую — вместе со своим парсером цен)

```bash
npm i -g vercel
vercel
```

Появится эндпоинт `https://твой-проект.vercel.app/api/price?url=...`.
Открой на сайте «Ещё» → «Свой сервис цен» → вставь этот адрес. Дальше цены идут через него:
свой User-Agent, без CORS-прокси, с кешем на 10 минут. Бесплатного тарифа хватает с запасом.

Netlify тоже подойдёт, но функцию нужно перенести в `netlify/functions/price.js` и поправить сигнатуру.

## Ограничения

Ozon, Яндекс.Маркет и Авито закрыты антиботом — цену оттуда придётся вписать руками.
Wildberries, Lamoda, DNS, Ситилинк, большинство обычных магазинов на CMS отдают всё нормально.
